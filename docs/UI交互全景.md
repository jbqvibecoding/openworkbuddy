# UI 交互全景

把这个项目里**所有能被人操作的界面**扒了一遍：每一处点击、拖拽、按键、右键、悬停、以及它背后
接的是哪个接口、代码在哪一行。按「载体 → 区域 → 交互」三层组织，方便照着改或照着补。

前端没有构建步骤、没有框架：`public/index.html` 是骨架，`public/js/app-0X.js` 顺序加载共享全局作用域，
改完刷新即生效。所以下面的行号就是真的能直接跳过去的位置。

### 3.2 带东西进来（三条路，口径完全一致）

| 路径 | 行为 |
|---|---|
| 回形针 `#attach-btn` | 唤起文件选择，多选上传 |
| 拖拽进窗口 | 拖到任意位置都认；输入卡片高亮 `.dragging`；拖文件即上传，拖选中文字：>2000 字存成 `.txt` 文件，否则插到光标处 |
| 粘贴 `⌘V` | 截图 → 按时刻重命名（`粘贴图片_MMDD_HHMMSS.png`）防同名覆盖；>2000 字的大段文字 → 存成 `粘贴文本_*.txt` 并 toast；短文字照常粘贴；焦点在别的输入框时不抢 |

共同规则（`app-02.js:154-330`）：
- 上限 30MB，超了 toast 跳过；图片 chip 带缩略图，文本 chip 带前 80 字 hover 提示。
- 文件落到**本对话的成果文件夹**，输入框里**不插任何标记**；发送时才在消息尾巴拼一句
  `（已上传文件：×××）`，气泡里再渲染成附件行。
- chip 上的 ✕ 只是「从这条消息移除」，文件仍在工作目录。

## 4. 对话流

一次回合的 UI 由 `createTurnUI()` 造（`app-01.js:527+`），**实时流式与历史回放共用同一套**。

### 4.1 用户气泡
- 右上角 ⧉ 复制原始输入（复制成功图标变 ✓ 1.2s）。
- 附件标记渲染成回形针行，不把内部标记糊到用户脸上。

### 4.2 过程区（折叠条 + 卡片）

| 元素 | 交互 |
|---|---|
| 折叠条 `.proc-head` | 点击展开/收起，偏好存 localStorage；常驻显示「运行中 mm:ss」+ 当前动作一行播报 + 工具徽章串 |
| 工具徽章 `.tc` | 合并同名工具并计数；点徽章 = 展开过程区 + 滚到最近那张卡并展开它；出错整枚标红 |
| 步骤卡 `.step-card` | 点头部展开参数/结果；标题是人话（`📄 读 报告.md`）；跑着的时候实时走秒，回来写死；行尾挂结果摘要（成功报量、失败报原因） |
| 里程碑卡 `.ms-card` | PROGRESS.md 的打勾清单，原地刷新 |
| 过程提示行 | `parallel` 并发、`compact`/`trim` 压缩、`failover` 换渠道、`limit` 触顶、`auto_continue` 续跑第 N 轮、`sleep` 本机睡眠顺延 |

流事件 → UI 的完整映射见 `app-01.js:774-1040`：`text / step_start / status / expert_start / parallel /
tool_use / tool_result / limit / auto_continue / sleep / failover / trim / compact / usage / trace /
dir / goal / title / interject / ask_user / ask_answer / credits / files / sources / milestones / error`。

### 4.3 正文区

| 元素 | 交互 |
|---|---|
| 流式 Markdown | 拆成「已定稿 / 正在写」两截渲染，排版与一次渲染完全一致 |
| 代码块 | 头部语言标签 + 「复制」（事件委托，历史与流式共用，带 execCommand 兜底） |
| 内联 SVG 信息图 | 五颗按钮：放大看 / 看源码 / 存矢量图 / 存图片 / 另存为…；点图本身也是放大 |
| 大图查看器 `.fig-zoom` | 全屏遮罩、滚轮缩放、按住拖动、百分比显示、Esc 退出 |
| 来源块 `.src-block` | 折叠/展开引用链接列表 |
| 成果文件名 | 正文里提到的产出名渲染成虚线下划线实体，点一下右侧打开预览（区别于会跳出去的外链） |
| 提示条 blockquote | 四色：核验没过 / 还没做完 / 原地打转 / 已通过，图标另起一列 |

### 4.4 提问卡（AI 拿不准时）
`app-01.js:1479-1560`：一条选项一行（短语 + 代价说明），**键盘 1–9 直选**（焦点在任何输入框里时不抢，
且只有屏幕上最后一张未答卡吃数字键），底部自由输入框 + 发送，右上角倒计时；超时服务端按默认继续，
卡片改写成「这个岔路我替你定了」；历史回放里直接标成过期不可点。

### 4.5 收尾工具条
`app-01.js:1140-1245`：
- **复制**：复制渲染后的富文本（同时写 text/html 与 text/plain），代码块的工具条不进剪贴板。
- **👍 / 👎**：真落库 `POST /api/feedback`，带模型、模式、耗时、tokens、步数、错误数；👎 之后再补一行
  「哪儿不对」（可选，Enter 记下 / Esc 取消）；回放时把之前点过的亮回来。
- **重新生成**：仅最后一轮有，服务端回滚最后一轮重跑。
- **看执行过程**：配了 Langfuse 时跳 trace 链接。

### 4.6 本回合产出块
`app-01.js:2240-2500`：
- 顶部一个开关（只有一层，点标题就把文件摊开）。
- **产出卡**：图/视频出缩略图（视频定格首帧）、PPT/Word/Excel/PDF 出大图标；卡上三颗按钮：预览（网页是「在浏览器打开」）/ 打开所在位置 / 下载；缩略图读不出来退回类型图标并说明原因。
- 同一件产出的副本（同名同大小、svg+png 同源）合并成一张卡，另一种格式挂在卡上。
- **变更清单**：没出卡的过程文件（脚本、日志、PROGRESS.md）沉底压暗；超量时「还有 N 个文件」再展开。
- 文件被删了：卡撤掉，清单行改成「已删除」并摘掉下载/定位入口（不抹掉这一行，抹掉等于帮 agent 圆谎）。

### 4.7 目标卡（Goal 模式）
`app-02.js:58-92`：常驻顶部，显示目标、进度条、`已达成 N/M 项 · 第 K 轮`、逐条勾选清单、
卡住原因；两颗按钮：✕ 归档目标、「接着冲」（只补没打勾的项，把烧不烧钱的决定交回用户）。

### 4.8 滚动与搜索

| 交互 | 行为 |
|---|---|
| 回到最新 `#to-bottom` | 往上翻远了出现；人在上面时下面来新内容会挂红点 |
| 回到最前 `#to-top` | 长对话往上翻时出现 |
| 对话内搜索 `⌘F` | 自建搜索条：实时计数、Enter 下一个 / Shift+Enter 上一个、↑↓ 按钮、Esc 关闭并把焦点还给输入框 |

### 4.9 空状态
`app-01.js:1342-1386`：四个场景 tab（日常办公 / 代码开发 / 设计创意 / 内容与增长，记住上次停留），
下面是分类胶囊；点胶囊不是直接发送，而是贴一枚「场景标签」到输入框上方（可 ✕ 摘掉），
发送时拼成 `【任务类型：…】` 前缀，并且不进会话标题。

## 14. IM 渠道交互（`im.js`）

飞书是最完整的一条：

1. 收到消息立刻贴一个**表情回执**（不发新消息、不刷屏）。
2. 随即发一张卡片，卡片里能看见**执行过程**（跑到第几步、动了哪个工具、给了什么文件），最多列 6 行，
   多了写「另有 n 步」；最快 1.2s 推一次。
3. 任务跑完，**同一张卡片原地变成最终回答**（打字机式流出）并撤掉表情。
4. 逐级降级：CardKit 流式 → CardKit 静态卡 → 普通交互卡 → 纯文本；正文超 4000 字或表格超 5 个时正文走文本消息，
   卡片里写一句「见下条」。
5. 失败时卡片也标成失败，不让用户盯着「准备开工…」发呆。

QQ / 企微 / 微信公众号走各自的消息形态（`im-qq.js` / `im-ilink.js` / `im-wechat.js`），媒体统一经 `im-media.js`。

## 15. 交互一致性的几条硬规矩

扒代码时反复出现、值得单独记下来的约定：

1. **点了没成必须说出来**：全仓库禁止 `.catch(() => {})` 吞掉用户发起的动作，403/501/超时都要 toast 出原因。
2. **能点的就得能用**：权限不够时不画按钮（画只读行 + 一句归属说明），而不是画一颗点了 403 的按钮。
3. **带进来的东西不进对话历史**：附件落盘 + 尾巴挂一句标记，图和大段文字绝不塞进上下文。
4. **视图开关不是删除**：「只看成果」藏了多少条要如实写在底下。
5. **不替 agent 圆谎**：文件被删了，卡撤掉但清单行改成「已删除」，发生过的事不抹。
6. **键盘要能走完全程**：div 做的行统一补 tabindex + Enter/空格，焦点圈自己画。
7. **主题不写死颜色**：所有色值走令牌，浅/暗两套都有对比度测试盯着（正文 ≥4.5、白字压主色 ≥3）。
